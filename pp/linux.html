The Linux Terminal

A working introduction for Programming for Physicists

The terminal is a text window in which you type commands and the computer replies. Almost every tool a physicist uses—compilers, ROOT, Geant4, Python scripts, remote clusters—is driven from here, so it pays to be comfortable with a handful of commands.

Open a terminal with Ctrl+Alt+T on most Linux desktops. You will see a prompt, something like:

student@lab:~$

This tells you the user name, the machine name, and the directory you are currently in (~). In the examples below, the $ stands for the prompt: do not type it. Text after # is a comment for you to read.

Where am I?

Files on Linux live in a tree of directories (folders). The top of the tree is /, called the root. Your personal directory is your home, usually /home/yourname.

pwd — print working directory

$ pwd
/home/student

The special names ~, . and ..

The tilde ~ is a shortcut the shell expands for you: ~/data becomes /home/student/data.Three short names are used constantly:

  • ~ — your home directory
  • . — the current directory
  • .. — the directory one level up (the parent)

Listing files: ls

ls lists what is in a directory. On its own it lists the current directory; give it a path to look elsewhere.

$ ls
data  notes.txt  programs
$ ls programs
hello.c  projectile.py

Options (also called flags) change the output. They start with a dash and can be combined.

$ ls -l        # long format: permissions, owner, size, date
$ ls -a        # show hidden files (names starting with .)
$ ls -lh       # sizes in human-readable units (K, M, G)
$ ls -lrt      # long format, sorted by time, oldest first

ls -lrt

Read the flags one by one: -l long, -r reverse, -t sort by modification time.This is the combination you will use most. Because the newest file appears last, right above your prompt, it is the quickest way to find the file your program just wrote.

$ ls -lrt
-rw-r--r-- 1 student student  1204 Oct 30 10:12 notes.txt
drwxr-xr-x 2 student student  4096 Nov  2 14:40 programs
-rw-r--r-- 1 student student 88310 Nov  5 09:03 output.dat

In each line, the first character is d for a directory and - for a file; then come the permissions, the owner, the size in bytes, the date of last change and the name.

Moving around: cd

cd (change directory) moves you to another directory.

$ cd programs       # go into programs (relative path)
$ cd ..             # go up one level
$ cd ../..          # go up two levels
$ cd /usr/include   # go to an absolute path
$ cd ~              # go home
$ cd                # also goes home
$ cd -              # go back to the previous directory

A path starting with / or ~ is absolute: it means the same thing wherever you are. Any other path is relative to the current directory.

Making, copying, moving, deleting

mkdir — make a directory

$ mkdir lab1
$ mkdir -p lab2/data/raw   # -p creates the parent directories too

touch — create an empty file

$ touch lab1/readme.txt

cp — copy

The pattern is always cp source destination.

$ cp notes.txt notes_backup.txt   # copy to a new name
$ cp notes.txt lab1/              # copy into a directory
$ cp -r lab1 lab1_copy            # -r copies a whole directory
$ cp ~/data/run01.dat .           # copy into the current directory

mv — move or rename

$ mv notes_backup.txt old_notes.txt   # rename
$ mv old_notes.txt lab1/              # move into lab1

rm — remove

There is no recycle bin in the terminal. A file removed with rm is gone. Use rm -i to be asked before each deletion.Be careful with this one.

$ rm lab1/readme.txt   # remove a file
$ rmdir lab2/data/raw  # remove an empty directory
$ rm -r lab1_copy      # remove a directory and everything in it

Wildcards

* matches any characters and ? matches exactly one, so you can act on many files at once.

$ ls *.py              # all Python files
$ cp run0?.dat backup/ # run01.dat ... run09.dat

Looking inside files

cat — print a whole file

$ cat notes.txt
$ cat part1.txt part2.txt   # print several files one after another

head and tail — the start or end of a file

Use head to check the column headers of a large data file without printing a million lines.By default these show ten lines.

$ head output.dat        # first 10 lines
$ head -n 3 output.dat   # first 3 lines
$ tail output.dat        # last 10 lines
$ tail -f run.log        # keep following a file as it grows

less — page through a file

Scroll with the arrow keys or Space, search with /, and quit with q.

$ less output.dat

wc and grep

$ wc -l output.dat        # count lines
$ grep energy notes.txt   # print lines containing "energy"

Editing with vi

On most systems vi is really vim. If you get stuck, press Esc a couple of times and type :q! to leave without saving.vi is an editor that runs inside the terminal and is available on every Linux machine, including remote servers where there is no graphical editor.

$ vi hello.c

The one idea to grasp is that vi has modes. It opens in normal mode, where keys are commands, not text. You press i to enter insert mode and type; you press Esc to return to normal mode.

Key (normal mode)What it does

aAppend text after the cursor
oOpen a new line below and insert
EscBack to normal mode
h j k lLeft, down, up, right (arrow keys also work)

ddDelete (cut) the current line
yyCopy (yank) the current line
pPaste below the cursor

:wqSave and quit

A complete first session: vi hello.txt, press i, type a line, press Esc, type :wq and press Enter. Then check with cat hello.txt.

A few more things worth knowing

Saving output and joining commands

$ ls -l > listing.txt       # send output to a file (overwrites)
$ echo "run 2" >> log.txt   # append to a file
$ ls -lrt | tail -n 3       # pipe: the three newest files
$ grep muon log.txt | wc -l # how many lines mention muon

Shortcuts that save typing

  • Tab completes file and command names. Press it twice to see all choices.
  • ↑ and ↓ step through previous commands; history lists them.
  • Ctrl+C stops a running program.
  • Ctrl+L (or clear) clears the screen.

Getting help

$ man ls      # the manual page for ls (quit with q)
$ ls --help   # a shorter summary of options

The .bashrc file

Files whose names start with a dot are hidden: plain ls does not show them, ls -a does.Every time you open a terminal, the shell (called bash) first reads and runs the commands in a hidden file in your home directory, ~/.bashrc. Anything written there happens automatically in every new terminal, so it is the place for settings you always want: shortcuts, and the setup commands for software such as ROOT or Geant4.

$ ls -a ~            # .bashrc is listed among the hidden files
$ tail ~/.bashrc     # look at its last few lines

Adding a line to .bashrc

Either open it with vi ~/.bashrc, go to the end with G, press o, type the line and save with :wq; or append the line in one go:

$ echo 'source ~/software/root/install/bin/thisroot.sh' >> ~/.bashrc

A single > here would replace the whole file with this one line, wiping out your existing settings.Be sure to type >>, which appends to the end of the file.

Making the change take effect

.bashrc is only read when a terminal starts, so changes do not affect terminals that are already open. Either open a new terminal, or reload it in the current one:

$ source ~/.bashrc

If a mistake in .bashrc causes error messages every time a terminal opens, edit the file with vi and remove or fix the line you added.
