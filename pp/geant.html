Building Geant4

Step-by-step instructions, from source code to a running example

Geant4 is the toolkit used to simulate how particles pass through matter and detectors. These steps build it from source. If the words source code, CMake, CMakeLists.txt or make -j4 are new to you, read Building (particle physics) software first.

Step by step

Replace the version number with the current one from the download page. Do each step in order, and check that it succeeded before moving on.

  1. Install the tools and common libraries

    sudo runs a command as the administrator and asks for your password. -dev packages contain the headers needed to build against a library, not just run it.You need a compiler, make, CMake, and the development packages of the libraries the software depends on. On Ubuntu or Debian:

    $ sudo apt update
$ sudo apt install build-essential cmake git wget \
      libexpat1-dev libxerces-c-dev libx11-dev libxmu-dev \
      libgl1-mesa-dev libglu1-mesa-dev qtbase5-dev
  2. Create the three folders 
    $ mkdir -p ~/software/geant4
$ cd ~/software/geant4
$ mkdir src build install
$ ls
build  install  src
  3. Download the source code into src

    Download the tarball and unpack it straight into src:

    $ wget https://gitlab.cern.ch/geant4/geant4/-/archive/v11.2.2/geant4-v11.2.2.tar.gz
$ tar -xzf geant4-v11.2.2.tar.gz -C src --strip-components=1

    --strip-components=1 drops the archive’s own top folder (geant4-v11.2.2/) so the files land directly in src.Check that CMakeLists.txt is there:

    $ ls src/CMakeLists.txt
src/CMakeLists.txt
  4. Go into the build folder 
    $ cd build

    Every remaining command, until the last step, is run from here.

  5. Configure with CMake

    Each -D sets an option. CMAKE_INSTALL_PREFIX says where make install will copy the result. The GEANT4_… options are specific to Geant4: download its physics data, and enable the Qt and OpenGL viewers.Tell CMake where the source is (../src) and where to install:

    $ cmake ../src \
      -DCMAKE_INSTALL_PREFIX=$HOME/software/geant4/install \
      -DGEANT4_INSTALL_DATA=ON \
      -DGEANT4_USE_QT=ON \
      -DGEANT4_USE_OPENGL_X11=ON

    Success ends with:

    -- Configuring done
-- Generating done
-- Build files have been written to: /home/student/software/geant4/build

    If you see CMake Error instead, read it carefully, fix the cause (see common errors) and run the same cmake command again.

  6. Compile with make 
    $ make -j4

    This is the long step. Progress is shown as a percentage. It has succeeded when it reaches [100%] with no line containing Error.

  7. Install 
    $ make install

    This copies the finished libraries, headers and programs into the install folder. Check:

    $ ls ../install
bin  include  lib  share
  8. Set up the environment

    This must be done in every new terminal. To make it automatic, see the next step.Your shell does not yet know where the new software lives. Geant4 provides a script that sets the necessary paths:

    $ source ~/software/geant4/install/bin/geant4.sh

    ROOT does the same with source install/bin/thisroot.sh.

  9. Make the setup permanent (optional)

    Use >> (append), never a single >, which would erase everything else in your .bashrc. Run the command only once.Instead of typing the source command in every new terminal, you can add it to your ~/.bashrc, a file that the terminal runs each time it starts (see what .bashrc does). Append the line with:

    $ echo 'source ~/software/geant4/install/bin/geant4.sh' >> ~/.bashrc

    Check that it was added as the last line:

    $ tail -n 1 ~/.bashrc
source ~/software/geant4/install/bin/geant4.sh

    Now open a new terminal (or run source ~/.bashrc) and check that Geant4 is found without any setup:

    $ geant4-config --version
11.2.2

    Skip this step if you keep several versions of Geant4, since an automatic setup can then pick the wrong one. To undo this, open ~/.bashrc in vi and delete the line.

  10. Test with an example

    Build and run the basic example B1, as described in the next section. If it runs, your Geant4 installation works.

Checking the examples: B1

Geant4 comes with many examples in src/examples, from basic to advanced. The simplest, B1, fires 6 MeV gamma rays into a box of water containing two shapes made of tissue and bone, and calculates the radiation dose deposited in one of them. Each example is a small program of its own that you build against your Geant4 installation, using the same cmake and make steps.

1. Set up Geant4 in this terminal

Skip this if you made the setup permanent:

$ source ~/software/geant4/install/bin/geant4.sh

2. Copy the example to your own folder

Always work on a copy, so the original in src stays untouched and you can start over at any time.Copy it out of the source tree and look at what it contains:

$ mkdir -p ~/g4work
$ cp -r ~/software/geant4/src/examples/basic/B1 ~/g4work/
$ cd ~/g4work/B1
$ ls
CMakeLists.txt  exampleB1.cc  exampleB1.in  exampleB1.out  include  init_vis.mac
README  run1.mac  run2.mac  src  vis.mac
  • exampleB1.cc — the main() program.
  • src/ and include/ — the detector geometry, the particle gun and the dose scoring.
  • *.mac — macro files: lists of Geant4 commands, read when the program runs.
  • exampleB1.out — a reference output to compare with yours.

3. Build it

$ mkdir build
$ cd build
$ cmake ..
$ make -j4

CMake also copies the .mac files into build, so the program can find them.The build has succeeded when the last line reads [100%] Built target exampleB1 and there is a program called exampleB1:

$ ls exampleB1
exampleB1

4. Run it interactively

$ ./exampleB1

A window opens showing the geometry: the water envelope with a cone and a trapezoid inside. At the bottom is a Session box where you type Geant4 commands. Simulate ten events:

/run/beamOn 10

Colours follow the particle’s charge: green for neutral (the gammas), red for negative (electrons), blue for positive.The particle tracks are drawn over the detector. Use the mouse to rotate and zoom. To leave, type exit in the session box or close the window.

5. Run it in batch mode

For real simulations you do not want graphics. Give the program a macro file, and it runs the commands in it and exits:

$ ./exampleB1 run2.mac > run2.out
$ grep -A 3 "End of Global Run" run2.out

Look inside with cat run2.mac: each /run/beamOn line starts a run, after setting the particle with /gun/particle and its energy with /gun/energy. run1.mac does the same with only a few events, but prints every step of every particle.The output is long, so we save it to a file and pick out the summary printed at the end of each run. It looks like this:

--------------------End of Global Run-----------------------
 The run consists of 1000 gamma of 6 MeV
 Cumulated dose per run, in scoring volume : 4.1 picoGy  rms = 2.0 picoGy
------------------------------------------------------------

There is one such summary per run in the macro, and the particle, energy and dose differ from run to run. Your numbers will also differ a little from these and from exampleB1.out, because the simulation uses random numbers. If you get output like this, both the Geant4 libraries and its physics data are working.

If B1 does not work

  • Could not find a package configuration file provided by "Geant4" during cmake ..: Geant4 is not set up in this terminal. Run step 1, empty build and try again.
  • An exception mentioning G4ENSDFSTATEDATA or another G4…DATA variable when running: the physics data is missing. Check that Geant4 was configured with -DGEANT4_INSTALL_DATA=ON and that geant4.sh has been sourced.
  • The program runs but no window opens, only a text prompt Idle>: Geant4 was built without Qt. Install qtbase5-dev, reconfigure Geant4 with -DGEANT4_USE_QT=ON, and rebuild. Meanwhile batch mode still works; type exit to quit.
  • error while loading shared libraries: libG4….so: as above, geant4.sh has not been sourced in this terminal.

The whole recipe

$ mkdir -p ~/software/geant4 && cd ~/software/geant4
$ mkdir src build install
$ tar -xzf geant4-v11.2.2.tar.gz -C src --strip-components=1
$ cd build
$ cmake ../src -DCMAKE_INSTALL_PREFIX=$HOME/software/geant4/install
$ make -j4
$ make install
$ source ../install/bin/geant4.sh

Download, configure, compile, install, set up. Nearly every package you will meet in particle physics is built this way.
