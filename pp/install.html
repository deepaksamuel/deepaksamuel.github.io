Getting started with installing particle physics software

Most of the software we use in particle physics—ROOT for analysis, Geant4 for simulation—is installed by building it from source code in a Linux terminal. The pages below take you there one step at a time. Work through them in order: each one assumes you are comfortable with the one before.

  1. Learn the terminal

    The Linux terminal — moving between directories, copying and deleting files, reading files with cat and head, editing with vi, and what the .bashrc file does.

  2. Understand how software is built

    Building (particle physics) software — what source code and compiling are, what CMake and CMakeLists.txt do, the src, build and install folders, make -j4, and the errors you are likely to meet.

  3. Build ROOT

    Building ROOT — step-by-step instructions for CERN’s data analysis framework, ending with your first histogram in C++ and in Python.

  4. Build Geant4

    Building Geant4 — step-by-step instructions for the detector simulation toolkit, and how to build and run the basic example B1.

  5. Install an editor

    Visual Studio Code, below — a comfortable place to read and edit the code of ROOT macros and Geant4 examples.

Installing Visual Studio Code

vi is still worth knowing: it is the editor you will have on a remote cluster where nothing else is installed.vi is fine for small changes, but for a Geant4 application spread over dozens of files you will want a full editor. Visual Studio Code (VS Code) is free, runs on Linux, and understands C++, Python and CMake.

  1. Install VS Code

    A .deb file is a software package for Debian-based systems such as Ubuntu. On Fedora or Red Hat, download the .rpm instead.On Ubuntu, the easiest way is the App Center (called Ubuntu Software on older versions): open it from the applications menu, search for Visual Studio Code, and click Install.

    Alternatively, go to code.visualstudio.com/download and click the .deb button for Debian and Ubuntu. Open your Downloads folder in the file manager, right-click the downloaded file, choose Open With… App Center (or Software Install), and click Install. You will be asked for your password.

  2. Start it

    Open the applications menu and search for Visual Studio Code. Right-click its icon in the dock and choose Pin to Dash (or Add to Favourites) to keep it there. To see which version you have, use Help → About.

  3. Install the extensions we use

    Many extensions have similar names. Check that the publisher is Microsoft, shown with a blue tick, before installing.Extensions add support for particular languages and tools. To install one:

    • Click the Extensions icon on the bar at the far left of the window—four small squares, one of them detached—or press Ctrl+Shift+X.
    • Type the extension’s name in the search box at the top of the panel.
    • Click the right entry in the list to see its description page, then click the blue Install button.
    • When it has finished, the button changes to a gear icon, and the extension appears under Installed in the panel.

    Install these three, all published by Microsoft:

    Search forWhat it gives you
    C/C++Colouring, auto-completion and error checking for C++ code such as Geant4 and ROOT macros
    CMake ToolsUnderstands CMakeLists.txt, and can configure and build a project from buttons in the status bar
    PythonSupport for Python scripts, including ones using import ROOT

    VS Code also suggests extensions on its own: when you first open a .cc or .py file, a message at the bottom right offers to install the recommended one. Clicking Install there does the same thing.

  4. Open a project folder

    VS Code works best when you open a whole folder rather than single files. Choose File → Open Folder…, browse to the folder—for example the Geant4 B1 example in g4work/B1 in your home folder—and click Open. The files appear in the Explorer panel on the left; click one to edit it.

    The first time, VS Code asks whether you trust the authors of the files in this folder; answer Yes for your own work.

  5. Use the built-in terminal

    This terminal reads your .bashrc like any other, so if you made the ROOT or Geant4 setup permanent, it is ready to use.Choose Terminal → New Terminal (or press Ctrl+`, the key below Esc). A terminal opens below the editor, already in your project folder, so you can build and run the code while you edit it.

If VS Code cannot find ROOT or Geant4 headers

VS Code may underline lines such as #include "G4RunManager.hh" in red, even though the program compiles. The editor simply does not know where the headers are. The easiest fix is to let CMake tell it: when the CMake Tools extension asks to configure the project, click Yes. For this to work, ROOT or Geant4 must be set up in your .bashrc (see the optional step in the ROOT and Geant4 guides); restart VS Code after changing it.
